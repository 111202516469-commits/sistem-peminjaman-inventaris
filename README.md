# Sistem Peminjaman Inventaris

## 1. Deskripsi Proyek
Sistem Peminjaman Inventaris adalah rancangan aplikasi untuk membantu proses pengelolaan data barang, peminjaman, dan pengembalian inventaris agar pencatatan lebih teratur dan mudah dipantau.

## 2. Identifikasi Masalah
Pencatatan peminjaman inventaris secara manual berisiko menimbulkan kesalahan penulisan, kehilangan catatan, kesulitan mengetahui ketersediaan barang, serta keterlambatan memantau pengembalian barang.

## 3. Manfaat Aplikasi
- Mempermudah pencatatan data barang dan transaksi peminjaman.
- Membantu petugas memantau ketersediaan serta kondisi barang.
- Memudahkan pencarian riwayat peminjaman dan pengembalian.
- Mengurangi risiko kesalahan pencatatan manual.

## 4. Target Pengguna dan Kebutuhan
- **Admin:** mengelola akun pengguna dan memantau seluruh data.
- **Petugas inventaris:** mengelola data barang, mencatat peminjaman dan pengembalian, serta memeriksa kondisi barang.
- **Peminjam (siswa/mahasiswa/guru/dosen):** melihat informasi barang dan mengajukan peminjaman sesuai prosedur.

Kebutuhan utama pengguna meliputi pencarian barang, informasi ketersediaan, pencatatan peminjaman, pencatatan pengembalian, serta laporan transaksi.

## 5. Fitur Utama
1. Login pengguna.
2. Dashboard ringkasan inventaris.
3. Daftar, pencarian, tambah, edit, dan hapus data inventaris.
4. Pencatatan peminjaman barang.
5. Pencatatan pengembalian dan kondisi barang.
6. Pengelolaan data pengguna.
7. Laporan dan riwayat peminjaman.
