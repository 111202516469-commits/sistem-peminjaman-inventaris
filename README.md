# Sistem Peminjaman Inventaris

## Deskripsi
Sistem Peminjaman Inventaris adalah aplikasi yang dirancang untuk mempermudah pengelolaan data barang, pencatatan peminjaman, pengembalian barang, dan pembuatan laporan inventaris.

## Tujuan
- Mempermudah pencatatan peminjaman barang.
- Memantau ketersediaan inventaris.
- Mencatat pengembalian dan kondisi barang.
- Mengurangi kesalahan pencatatan secara manual.

## Target Pengguna
- Admin
- Petugas inventaris
- Siswa atau mahasiswa
- Guru atau dosen

## Fitur Utama
1. Login pengguna
2. Dashboard
3. Pengelolaan data inventaris
4. Peminjaman barang
5. Pengembalian barang
6. Pengelolaan pengguna
7. Laporan peminjaman

## Struktur Proyek
